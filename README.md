# focp_oel
A C++ text based cryptographic game featuring 5 levels of Shift and Reverse Cipher puzzles. Decode encrypted numbers, solve challenges, earn points, and unlock the next level.
CODE BREAKER GAME
Code Breaker is a simple text-based cryptographic game developed in C++. The player has to decode encrypted numbers and complete 5 levels to win.

FEATURES:

1.5 challenging levels.

2.Two techniques: Shift Cipher and Number Reversal.

3.2 attempts per level.

4.10 points for each completed level.

5.Maximum score of 50 points.

6.Next level unlocks only after completing the previous one.

PROGRAMMING CONCEPTS USED:

1.Functions

2.Loops (for, while, do-while)

3.Nested loops

4.if-else and switch

5.break and continue

6.Arithmetic operators (% and /)

7.Pass by reference

HOW TO PLAY:

1.Run the C++ program.

2.Select an option from the menu.

3.Read the hint and decode the encrypted number.

4.Enter your answer within two attempts.

5.Complete all five levels to get the maximum score!
